Versjonar

Sida viser dei nyaste versjonane på main. Ei gjenoppretting skjer ikkje direkte her. Knappen opnar den sikra arbeidsflyten i GitHub, der du må logge inn, velje versjon og skrive GJENOPPRETT.

Tryggleik: Hovudportalen vert ikkje endra berre ved å opne denne sida. GitHub krev skrivetilgang og eksplisitt stadfesting før ei eldre utgåve kan gjerast til ny produksjonsversjon.
